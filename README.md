# Tanks3D (Танчики 3D) — Android TV

3D-игра в духе Battle City для телевизора: широкое поле 16:9, пульт и геймпады, игра вдвоём.

**Скачать:** [Tanks3D.apk](../../releases/latest/download/Tanks3D.apk)

APK собирается автоматически (GitHub Actions) при каждом изменении в ветке `main`.
Игра лежит в `app/src/main/assets/game/`.
